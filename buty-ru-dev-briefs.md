# Buty.ru — пакет брифов для разработки в Kimi K3 (Goal-режим)

**Как пользоваться:** один бриф = один новый чат. Рабочие чаты (1–9): вставляете `PROJECT CARD` + `HANDOFF предыдущей части` + `БРИФ ЧАСТИ N`. Больше ничего давать не нужно — брифы самодостаточны. Исключение — нулевой чат (часть 0): ему нужен PROJECT CARD + **все 9 брифов целиком**, он их сверяет и готовит репозиторий.

**Принципы экономии лимитов (уже вшиты в брифы):**
- Стек зафиксирован — Kimi не тратит токены на выбор технологий и обоснования.
- Жёсткие границы: «не трогай файлы вне списка», «не добавляй фичи», «не рефактори чужой код».
- Отчёт Kimi ограничен: ≤20 строк + HANDOFF-блок фиксированного формата.
- Каждая часть завершается работающим состоянием — никаких «доделаем в следующем чате» внутри одной части.

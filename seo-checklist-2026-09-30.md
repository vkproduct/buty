### 2. Контент — риск тонких страниц (основная находка аудита)
Часть карточек ингредиентов (автоимпортированные) имеет дублирующиеся/короткие описания вида «очищение; пенообразование» без концентрации и разбора. Примеры из выдачи каталога:
- `ammonium-laureth-sulfate`, `ammonium-lauryl-sulfate`, `caprylyl-capryl-glucoside` — описание = сырой список функций
- `benincasa-cerifera-seed-extract`, `chondrus-crispus`, `collagen-extract` — «уход за кожей»
- [ ] Выгрузить из БД все ингредиенты с description < 150 символов или description, совпадающим с функциями INCI
- [ ] Приоритезировать по трафиковым запросам Wordstat (топ-100)
- [ ] Дописать уникальные разборы или временно закрыть noindex карточки без контента (чтобы не тратить краул-бюджет Яндекса)
- [ ] Для остальных поставить задачу наполнения пачками по 50 шт.

### 3. Техника

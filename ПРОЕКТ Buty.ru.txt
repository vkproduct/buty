ПРОЕКТ: Buty.ru — сервис разбора составов косметики с научным дерматологическим
подходом. Бесплатно: разбор состава (текст) + базовый подбор ухода.
Платно: «Моя полка» — коллекция средств с проверкой совместимости активов,
порядком нанесения, поиском дублей, историей реакций кожи, напоминаниями.
Монетизация: подписка, партнёрские ссылки (WB/Ozon/Золотое Яблоко), бренды.
Аудитория: женщины 20–40, читают составы, покупают на WB/Ozon/ЗЯ.

СТЕК (ФИКСИРОВАН, НЕ МЕНЯТЬ): Next.js 14 App Router + TypeScript + TailwindCSS +
shadcn/ui + PostgreSQL + Prisma + NextAuth (email-magic-link). Никаких новых
фреймворков, БД, стейт-менеджеров. Минимум зависимостей.

СТРУКТУРА РЕПО: /app (маршруты), /components, /lib (логика), /prisma (схема +
seed), /public. Не создавать новые корневые директории без необходимости.

ДИЗАЙН (ФИКСИРОВАН): глубокий лавандовый #5B4BC4, мягкий коралловый #F7A58C,
янтарный #E8B84B, фон #F6F4FB; стекломорфизм (backdrop-blur, полупрозрачные
карточки), плавные градиенты. БЕЗ зелёно-оранжевой «эко»-палитры. Типографика:
Inter + Manrope. Премиальный, технологичный вид.

ПОЗИЦИОНИРОВАНИЕ: доказательная наука, НЕ «натуральное = хорошо». Для каждого
ингредиента: функция, типичная рабочая концентрация, конфликты с другими
активами, уровень доказательности.
